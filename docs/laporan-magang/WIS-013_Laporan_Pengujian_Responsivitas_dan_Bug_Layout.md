## 2. Inventaris 23 Poin Temuan Evaluasi (Progress 1)
Temuan evaluasi yang berhasil dihimpun mencakup:
1. Perlunya masking identitas warga pada tampilan umum.
2. Peniadaan popup izin deteksi koordinat GPS otomatis.
3. Penyelarasan notifikasi konfirmasi laporan.
4. Penyederhanaan logo navbar publik (menghapus teks redundant).
5. Pemisahan formulir laporan ke halaman mandiri (`/lapor` & `/lacak`).
6. Penataan hero banner satu layar penuh (100vh).
7. Konsistensi border radius (`rounded-xl` & `rounded-lg`).
8. Sidebar admin tidak ikut terscroll saat konten digulir.
9. Isolasi navbar publik agar tidak muncul di halaman admin.
10. Penambahan paginasi pada tabel warta berita.
11. Pencarian reaktif *on-chain* (tanpa klik tombol cari).
12. Abstraksi komponen tabel reusable.
13. Komponen uploader foto bergaya Shadcn UI.
14. Sidebar admin yang bisa diperkecil (*collapsible*).
15. Modal pratinjau dokumen publik.
16. Modal lightbox galeri kegiatan.
17. Penyeragaman panel superadmin.
18. CMS struktur organisasi dinamis.
19. Refaktor arsitektur kode reusable.
20. Penyeimbangan grid kartu berita.
21. Penyeimbangan grid kartu dokumen.
22. Pengalihan tombol login publik ke rute `/login`.
23. Standardisasi palet warna resmi Cokelat Praja (`#3d261a`).
